## 5. Contention

The rule tonight: a measured repetition with a **host** CPU sample (before generate or after verify) over 25 % sends the item back for one rerun from reset. A guest `load1` over 4.0 is noted only, as the run's own load.

Measured repetitions with a host sample over 25 %: **3 of 5** (m1 start 26.0 %, m2 start 28.2 %, m3 end 25.1 %). Guest: 3 of 5. The rerun was already used on attempt 1, so **this attempt stands, flagged**. All three host flags are within 3.2 points of the line. m4 and m5 have no host flag and are faster (636, 602 TPS) than m1–m3 (482–536). So the median here may understate the uncontended value somewhat.

Cause: the user was using Brave on the desktop at the time. A 5 s process sample at 01:25 showed Brave at about 1.9 cores, Explorer 0.35, Docker Desktop about 0.45 and `mpv` running. The coordinator later paused the night at the user's request until Brave was closed (study log, 01:57–02:49).
